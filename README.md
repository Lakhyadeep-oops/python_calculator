# Python Calculator (Git/GitHub Challenge Lab)

## 📌 Project Description
This project is a simple Python calculator built to demonstrate the use of **Git and GitHub** concepts such as:
- Creating repositories
- Working with branches
- Committing changes
- Raising Pull Requests (PR)
- Merging branches into main

The project performs basic arithmetic operations using **modular Python files**.

---

## 🛠 Technologies Used
- Python 3
- Git
- GitHub

---

## 📂 Project Structure
python_calculator/
│
├── main.py # Main program file
├── sum.py # Module for addition
├── diff.py # Module for subtraction
├── README.md # Project documentation

---

## ⚙️ How the Project Works
- Each arithmetic operation is written in a **separate Python module**
- New features were developed in **separate branches**
- Each branch was merged into the `main` branch using **Pull Requests**

---

## 🌿 Git Branch Strategy
- `main` → Stable branch
- `feature-sum` → Addition module
- `feature-diff` → Difference module

Each feature branch was:
1. Created from `main`
2. Committed with changes
3. Pushed to GitHub
4. Merged via Pull Request
