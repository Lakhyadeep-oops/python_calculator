# Python Calculator (Git/GitHub Challenge Lab)

## 📌 Project Description
This project is a simple Python calculator built to demonstrate the use of **Git and GitHub** concepts such as:
- Creating repositories
- Working with branches
- Committing changes
- Raising Pull Requests (PR)
- Merging branches into main

The project performs basic arithmetic operations using **modular Python files**.

---

## 🛠 Technologies Used
- Python 3
- Git
- GitHub
